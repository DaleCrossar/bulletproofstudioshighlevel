# The Memory Room: Instagram posts, batch 1

Six carousels in the brand system from the Memory Room Canva brand kit and previous posts: the real paper background and logo, headlines in `#7a4e3a` (Fraunces Soft, the match for the Canva headline font), Jost sublines, the "Comment your answer below" line, and the **Capture their story** end slide.

Rendered slides live in the `post-*` folders. To change any text, edit `_src/posts.json` and run `node _src/render.js`.

**Suggested order:** 6 → 3 → 1 → 4 → 5 → 2.

**Sound:** add slow, wordless piano from the Instagram library when posting.
